
# 🚀 AI Career Intelligence

An AI-powered career assistance platform built using Python and FastAPI.

## Features

- User Registration and Login
- Resume Upload and Parsing
- AI Job Matching
- ATS Compatibility Checker
- Skill Gap Analysis
- Career Recommendations
- What-If Career Simulator
- AI Interview Preparation
- Personalized Learning Roadmap
- PDF Report Generation
- Interactive Web Dashboard

## Technologies

- Python
- FastAPI
- SQLAlchemy
- SQLite
- HTML, CSS, JavaScript
- Scikit-learn
- PyMuPDF
- ReportLab

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
uvicorn app.main:app --reload
```

Open:

http://127.0.0.1:8000/

API Documentation:

http://127.0.0.1:8000/docs

## Security

Never upload passwords, secret keys, personal resumes or database files.
